<h3 align="left">Hi! I'm Alejandro Betancourth, a full stack developer from Bogotá working with AI.</h3>

I work mostly with Node.js, React and Python. For the past year I worked at a facial biometrics company, where I retrained YOLO models for face validation and built the Node.js and Flask backends that serve them. On my own I build applications with LLMs and computer vision.

### Projects

| Project | What it is | Demo |
|---|---|---|
| [llm-liveness](https://github.com/alejandroberod/llm-liveness) + [liveness-api](https://github.com/alejandroberod/liveness-api) | Face liveness detection that combines an anti-spoofing CNN (Silent-Face on ONNX, served from Flask) with Gemini as a second check | [Try it](https://alejandrobetancourth-llm-liveness.vercel.app) |
| [ragChatbot](https://github.com/alejandroberod/ragChatbot) | Chat with your PDFs: Next.js, Postgres with pgvector (HNSW) and Gemini | [Try it](https://alejandrobetancourth-ragchatbot.vercel.app) |
| [dalleClon](https://github.com/alejandroberod/dalleClon) | Image generation with a community gallery: React, Express, MongoDB and Cloudinary | [Try it](https://alejandrobetancourth-dalleclon.vercel.app) |
| [AI-Tac-Toe](https://github.com/alejandroberod/AI-Tac-Toe) | Tic-tac-toe against an LLM whose moves are validated on the server | [Try it](https://alejandrobetancourth-ai-tac-toe.vercel.app) |
